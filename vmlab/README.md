# 🧠 Ultimate Hands-On Lab Course: Network Administration, Cybersecurity & AI-Powered Forensics on Ubuntu VM

This repository provides the complete **Hands-On Lab Course** for learning **system and network administration**, **network security**, and **AI-assisted forensic investigation** — all fully runnable on **local virtual machines (VMs)** using **Ubuntu 24.04**.  

Students can now migrate from cloud-based environments to **VMware Workstation or VirtualBox**, allowing complete hands-on practice without relying on external cloud resources.

---

## 🚀 Course Overview

This course combines **practical network administration**, **security operations**, and **AI applications in cybersecurity**.  
You will learn how to **deploy, monitor, and secure** IT infrastructures using industry-standard open-source tools and explore **AI-enhanced vulnerability assessment** and **forensic analysis** techniques.

---

## 🧰 System & Network Administration Labs

Install, configure, and manage essential infrastructure and monitoring tools:

- **Network Monitoring:** SNMPD, MRTG, ntop-ng
- **Performance Monitoring:** TIG Stack (Telegraf, InfluxDB, Grafana)
- **Service Monitoring:** Nagios

Each tool is demonstrated step-by-step with configurations that mimic real-world enterprise deployments.

---

## 🛡️ Network Security Tools & Attack Simulation

Understand and analyze network security through **hands-on attack and defense exercises**:

- **Vulnerability Scanning:** Nmap  
- **Penetration Testing:** Metasploit Framework (msfconsole)  
- **Intrusion Detection & Prevention:** Suricata IDS/IPS  
- **Attack Scenarios:**
  - Distributed Denial of Service (**DDoS**)
  - Man-in-the-Middle (**MITM**) via ARP poisoning
  - **DNS Spoofing and Hijacking**

All scenarios are performed safely in isolated virtual environments.

---

## 🤖 AI in Vulnerability Assessment & Forensic Investigation

Discover how **Artificial Intelligence (AI)** and **Large Language Models (LLMs)** can enhance cybersecurity workflows:

- Automate vulnerability assessments  
- Analyze network logs using AI  
- Identify attack patterns through NLP-based models  
- Conduct AI-assisted forensic investigations  

These labs demonstrate how modern AI tools can augment a security analyst’s decision-making and improve incident response efficiency.

---

## ⚙️ Platform & Environment Setup

- **Operating System:** Ubuntu 24.04 LTS  
- **Virtualization Platform:** VMware Workstation / VirtualBox  
- **Docker Labs:**
  - Kali container with **msfconsole** and **nmap**
  - Metasploitable container in a **private internal network**

All environments are pre-configured to ensure seamless student lab experience.

---

## 🎯 Learning Outcomes

By completing this lab course, students will be able to:

- Configure and manage real-world network and system services  
- Monitor infrastructure performance and security events  
- Simulate and analyze network attacks safely  
- Integrate AI for vulnerability assessment and digital forensics  
- Build a self-contained cybersecurity lab on a local workstation
